Tessalytics

Privacy Policy

Effective August 19, 2026

The short version: Tessalytics collects nothing. There is no Tessalytics account, server, relay, or cloud backend. Your iPhone talks directly to the TeslaMate server you configure — and, only if you choose to enable it, directly to Tesla. No advertising, no analytics SDK, no tracking, no maintainer telemetry.

What Tessalytics is

Tessalytics is a native iPhone client for a self-hosted TeslaMate installation. It reads vehicle status, drive history, and charging history from your own TeslaMateApi deployment and turns that data into dashboards, charts, analytics, battery estimates, and forecasts computed on your device.

Tessalytics is an unofficial community tool and is not affiliated with, endorsed by, or supported by the official TeslaMate project or Tesla, Inc.

Data the developer collects

None. Tessalytics has no account system, no backend service, and no developer-operated infrastructure of any kind. The developer never receives your vehicle data, location, routes, VIN, server address, credentials, tokens, crash data, or usage statistics.

Where your data goes

  • Your TeslaMate server. The app makes network requests only to the TeslaMateApi address you enter. Where that server runs, who can reach it, and how long it retains data are entirely under your control.
  • Tesla, only if you enable it. Advanced users may add an Owner API access/refresh-token pair generated outside Tessalytics. When present, the app communicates directly with Tesla for live state and for commands you explicitly confirm. Token refresh also happens directly between your iPhone and Tesla.
  • Apple Maps. Route and location maps are drawn with Apple's MapKit, which is subject to Apple's privacy policy.

The app never asks for your Tesla account password, and it contains no third-party analytics, advertising, attribution, or tracking code.

Credentials

  • TeslaMate bearer tokens and HTTP Basic credentials are stored only in the iOS Keychain, protected with kSecAttrAccessibleAfterFirstUnlock.
  • Optional Tesla Owner API access and refresh tokens are stored in a separate Keychain item with kSecAttrAccessibleWhenUnlockedThisDeviceOnly, so they are readable only while the device is unlocked and never migrate to another device or backup.
  • Credentials are never written to the app database, UserDefaults, Info.plist, source code, or diagnostics.

Data stored on your device

For offline browsing and fast startup, Tessalytics caches vehicle metadata, drive and charging history, route samples, battery-health observations, firmware history, and synchronization metadata. Records are partitioned by server profile and vehicle, and are protected by the standard iOS app container and data protection.

A cached snapshot is never presented as current after a failed refresh — offline data is labeled stale. Deleting a server profile removes its credentials; deleting the app removes its entire local database.

Vehicle commands

With the optional Owner API connection enabled, Tessalytics can send user-initiated lock, climate, charging, and trunk commands directly to Tesla. Every command requires an in-app confirmation plus successful Face ID or device-passcode authentication. Tessalytics never wakes a sleeping vehicle automatically and never sends commands in the background.

Notifications

Alerts for low battery, charge completion, software updates, and notable changes are optional local notifications scheduled on your device. There is no push server, and no notification content leaves your iPhone.

Demo mode

The built-in demo generates sample drives and charging sessions entirely on your device. It requires no Tesla, no account, no server, and no network connection, and it never enables vehicle commands.

Diagnostics

Application logs stay on your device and are redacted: they must not contain authorization headers, passwords, tokens, VINs, coordinates, addresses, or vehicle names. Nothing is transmitted to the developer. If you file a bug report, please review any logs you choose to attach.

Children's privacy

Because Tessalytics collects no data from anyone, it collects no data from children.

Changes to this policy

If a future version changes any of the above, this page will be updated before that version ships, with a new effective date.

Contact
